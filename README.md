# stock-rating-project
BUILT A STOCK ALGORITHMIC RATING PROGRAM based on chart patterns, indicators,company ratios and news sentiments (currently built for apple)
done: 1)extraction of candle data. 
      2)coded atr. 
      3)coded sma. 
      4)ema
      5)rsi
      6)support/resistance
      7)fundamental_analysis score using YahooFinance 
      8)sentimental_analysis score using Vader
      9)chart_buy_rating score using logistic regression
      10)normalised all scores to produce a master buy rating
      11)buy rating gauge using Plotly with execution text including buy/hold/sell
